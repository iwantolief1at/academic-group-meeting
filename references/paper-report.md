# 论文模式

按“问题 → 方法 → 实验结论”组织；对约 10–15 分钟汇报可规划 8–12 张内容页，随论文与用户要求调整。不要强制使用所有章节。

建议覆盖：基本信息；研究背景/问题；现有不足；核心贡献；整体架构与完整数据流；重点模块；实验设置；主结果/消融/可视化；局限；对遥感小目标检测的启发。

基本信息以论文首页与正式出版信息为准，未联网核实的会议/年份不能根据文件名猜测。论文不存在的信息用“未说明/待确认”。引用外部资料时核验原文；仅有用户本地论文时可直接引用其页码，不要求额外联网。

方法图优先原始结构图。解释输入、输出、尺寸/尺度变化、训练与推理分支；无法看清的尺寸注明未知。公式页最多一个主公式或一组紧密相关公式，说明它解决的问题、符号、作用路径及论文中的位置。简化公式要明确是讲解化表达。

实验表同时写数据集、划分、指标定义和是否作者报告/本地复现；不同设置分表。消融页解释开关与参照行，标清提升是绝对百分点还是相对百分比。不要将单次消融或不可比条件解释为普遍因果。

页面可使用“作者结论”“直接证据”“我们的推断”标签。批判性分析关注小目标漏检、背景干扰、尺度、旋转、密集目标、推理成本与数据划分，只写资料支持的点。迁移到遥感方向的建议写成待验证假设，区分通用遥感光学目标与红外弱小目标，不默认它们是相同任务。

结尾提出一至三个可检验启发，说明需要什么实验确认；源论文没有开放设置时把复现缺口列出。报告中不能使用 `examples/paper/` 的虚构论文身份或结果作为新论文资料。
